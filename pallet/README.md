# Storage Provider Pallet

Substrate FRAME pallet implementing the on-chain logic for Scalable Web3
Storage: provider registration and staking, bucket creation, storage agreements,
MMR-based checkpoints, and the challenge/slashing mechanism.

## Build & Test

```bash
cargo build -p storage-provider-pallet --release
cargo test -p storage-provider-pallet
```
