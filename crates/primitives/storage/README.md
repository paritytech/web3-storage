# Storage Primitives

Shared types and utilities used across the pallet, provider node, and client
SDK — including storage agreement structs, checkpoint types, MMR definitions,
and common error types.

## Build & Test

```bash
cargo build -p storage-provider-primitives --release
cargo test -p storage-provider-primitives
```
