    Content addressing

    • • Chunks and internal nodes are both addressed by hash
    • • Upload is bottom-up: children must exist before the parent
    • • If the root hash exists, the whole tree is present

    One MMR per bucket

    • • Append adds a leaf; delete raises start_seq; freeze locks start_seq
    • • Canonical range: [start_seq, start_seq + leaf_count)
    • • Non-canonical [A, A+N) is prunable once canonical [B, B+M) has B+M > A+N

    What a proof must show

    • • chunk_proof (MerkleProof): the chunk is in the leaf's data_root
    • • mmr_proof (MmrProof): peaks, leaf and leaf_proof to the mmr_root
    • • If either check fails, the response is rejected with InvalidProof and the challenge stays open
