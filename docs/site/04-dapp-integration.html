    Semantic radar needs more MAP space.

    Setup and write

    • • Create the bucket with create_bucket_with_primary, or create_bucket then add_primary_provider
    • • Primaries do not sync with each other: upload to every primary
    • • Keep the provider_signature from POST /commit: it is the evidence for challenge_offchain
    • • checkpoint takes a GET /checkpoint-signature signature from at least min_providers primaries

    Challenge modes

    • • challenge_offchain: with a commit signature; for buckets with frequent writes
    • • challenge_checkpoint: against the on-chain snapshot; for cold buckets
    • • challenge_replica: against the root a replica confirmed on-chain
    • • The provider has ChallengeTimeout to respond (12 Challenge protocol)

    Keep the data stored

    • • extend_agreement before expiry; end_agreement Pay or Burn within SettlementTimeout
    • • add_replica_provider with a replica quote for more redundancy
    • • Change a primary: add the new one, upload, checkpoint with its signature (14 Changing a primary provider)
