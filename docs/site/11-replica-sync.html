    Semantic radar needs more MAP space.

    Chain first

    • • The replica reads the MMR root from the chain, not from a provider
    • • It checks peaks against that root before the traversal starts
    • • A source that serves wrong data fails the first hash check

    Top-down walk

    • • A matching hash skips the whole subtree
    • • Unchanged subtrees are detected at their first node
    • • Sync state is the set of missing nodes, so a sync can resume
    • • POST /exists checks which nodes a provider has

    confirm_replica_sync

    • • roots: current snapshot plus 6 historical_roots positions (primes 3, 7, 11, 23, 47, 113)
    • • The first matching position is credited: position_matched 0 is current, 1-6 historical
    • • Rejected unless the root differs from last_sync and min_sync_interval has passed
    • • A confirmed root makes the replica challengeable by anyone
    • • Anyone can fund syncs with top_up_replica_sync_balance

    Private buckets

    • • Primaries serve reads only to members; provider accounts are not members
    • • A replica syncs from other replicas or any data holder instead of the primaries
    • • Replicas serve everyone, on public and private buckets
