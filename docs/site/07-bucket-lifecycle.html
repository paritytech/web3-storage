    Semantic radar needs more MAP space.

    Creation

    • • create_bucket: anyone; caller is sole admin; bucket_id assigned and never changes
    • • create_bucket_with_primary: bucket and first primary in one call, min_providers = 1
    • • add_primary_provider: bucket admin, below MaxPrimaryProviders

    Checkpoint and freeze

    • • checkpoint needs min_providers primary signatures and records primary_signers
    • • freeze_bucket: admin only, irreversible, needs a snapshot with min_providers acknowledgments
    • • Frozen: start_seq cannot decrease below frozen_start_seq

    Without providers

    • • Ending the last agreement deletes the agreement, not the bucket
    • • Members, snapshot and frozen_start_seq remain; a frozen bucket stays frozen
    • • add_primary_provider works on a bucket with zero primaries and on a frozen bucket

    Visibility

    • • Admin only, both directions, no precondition on replicas
    • • Public to Private: gates new appends; replicated data stays public
    • • Private to Public: the disclosure cannot be undone
    • • On-chain effect: Private limits primary challenges to members and primary-agreement owners
