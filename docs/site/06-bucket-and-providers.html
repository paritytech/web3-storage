    Who may call

    • • create_bucket: anyone; the caller becomes sole admin
    • • create_bucket_with_primary: terms.owner; creates the bucket with min_providers = 1
    • • add_primary_provider: bucket admin (NotBucketAdmin)
    • • add_replica_provider: terms.owner, any account the provider quoted

    Shared checks on signed terms

    • • terms.bucket matches the call (TermsBucketMismatch); terms.owner matches the origin (TermsOwnerMismatch)
    • • now <= terms.valid_until <= now + RequestTimeout (TermsExpired / TermsValidityTooLong)
    • • Signature over blake2_256(context | SCALE(terms)); terms.nonce equals AgreementNonces[owner], which redemption advances (NonceMismatch)
    • • Provider active, terms.max_bytes > 0 and within capacity and stake (CapacityExceeded / InsufficientStakeForBytes)
    • • The client reads AgreementNonces[owner] at the best block and sends it as nonce; the provider signs it unchanged. One quote per nonce: on NonceMismatch, read it again and request a new quote

    Role-specific checks

    • • Primary: replica_params = None, ProviderNotAcceptingPrimary, MaxPrimaryProvidersReached
    • • Replica: replica_params = Some (MissingReplicaTerms), ProviderNotAcceptingReplicas
    • • Existing bucket: BucketNotFound, AgreementAlreadyExists
    • • Held payment: terms.price_per_byte * terms.max_bytes * terms.duration
